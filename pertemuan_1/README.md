# Pertemuan 1 — Pengantar Big Data & Arsitektur Sistem

## Ringkasan Materi
Pada pertemuan pertama, materi berfokus pada pengenalan teori dan konsep dasar Big Data:
1. **Karakteristik Big Data (5V)**: Volume, Velocity, Variety, Veracity, Value.
2. **Arsitektur Komputasi Terdistribusi**: Konsep master-worker, shared-nothing architecture, fault-tolerance.
3. **Ekosistem Big Data**: Apache Hadoop (HDFS, YARN, MapReduce) dan Apache Spark.
4. **Persiapan Lingkungan Praktikum**: Kebutuhan instalasi Linux, Java JDK 8/11, Hadoop, Spark, dan Python environment.
